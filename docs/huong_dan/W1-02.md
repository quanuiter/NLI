# W1-02 – Vào repo GitHub và commit thử (Quang)

**Mục tiêu:** m có quyền chỉnh sửa repo chung [quanuiter/nli](https://github.com/quanuiter/nli) và đã commit thử thành công.

## Cần có trước
- Tài khoản GitHub. T đã gửi lời mời collaborator rồi.

## Các bước
1. Mở email của GitHub có tiêu đề kiểu *"invited you to collaborate on quanuiter/nli"* → bấm **Accept invitation**.
   Không thấy email thì vào thẳng link: <https://github.com/quanuiter/nli/invitations>.
2. Mở repo, đọc lướt `README.md` để biết repo có những gì.
3. Commit thử ngay trên web, không cần cài gì:
   - Mở file `docs/thanh_vien.md` → bấm **biểu tượng cây bút chì** (góc phải).
   - Ở dòng A, sửa "Quang" thành họ tên đầy đủ của m.
   - Bấm nút xanh **Commit changes…** → để mặc định *Commit directly to the main branch* → bấm **Commit changes**.
4. Vào tab **Commits** của repo, thấy commit mới đứng tên m là được.

## Tự kiểm tra
- Commit đứng tên m hiện trên GitHub.

## Khi xong
- Đổi W1-02 sang **Hoàn thành** trong kế hoạch.
- Làm luôn bước *Thêm Drive chung* ở [README hướng dẫn](README.md).
- Lưu ý: **không** đưa file trong `data/processed/` lên GitHub (file lớn, repo đã chặn sẵn bằng `.gitignore`).

# W1-02 – Vào repo GitHub và push thử (phần của A – Quang)

**Mục tiêu:** Quang có quyền push lên repo [quanuiter/nli](https://github.com/quanuiter/nli) và đã push thử thành công.

## Cần có trước
- Tài khoản GitHub. Quân đã gửi lời mời collaborator.

## Các bước
1. Mở email GitHub "invited you to collaborate on quanuiter/nli", hoặc vào <https://github.com/quanuiter/nli/invitations> → **Accept invitation**.
2. Mở repo, đọc `README.md` (mục *Quy ước dùng chung*): cách gọi `load_scenario` và `evaluate_and_save`.
3. Push thử, chọn **một** trong hai cách:
   - **Trên web (dễ nhất):** mở `docs/thanh_vien.md` → biểu tượng bút chì → điền họ tên đầy đủ của mình vào dòng A →
     **Commit changes** → chọn *Commit directly to the main branch*.
   - **Bằng git:**
     ```bash
     git clone https://github.com/quanuiter/nli.git && cd nli
     git config user.name "Tên của bạn"; git config user.email "email-github-cua-ban"
     # sửa docs/thanh_vien.md, rồi:
     git add docs/thanh_vien.md && git commit -m "Thêm tên thành viên" && git push origin main
     ```
4. Kiểm tra commit hiện trong tab **Commits** của repo.

## Tự kiểm tra
- Commit đứng tên Quang hiện trên GitHub.

## Khi xong
- Đổi W1-02 sang **Hoàn thành** trong kế hoạch.
- Từ giờ: **luôn `git pull` trước khi sửa**. Không đưa file trong `data/processed/` lên GitHub (đã chặn bằng `.gitignore`).

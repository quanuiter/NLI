# W2-02 – Phân tích thủ công 25 mẫu ViANLI (Quang)

**Mục tiêu:** với 25 mẫu ViANLI (stt 26–50) trong `data/manual/50_mau.csv`, gắn thẻ hiện tượng ngôn ngữ và giải thích vì sao mẫu có nhãn đó.
Đây là phần **phân tích thủ công** bắt buộc của đồ án (slide 21).

## Cần có trước
- **Đã xong W2-03.** Chưa xong thì không mở `50_mau.csv`.
- Đọc [huong_dan_gan_the.md](../../data/manual/huong_dan_gan_the.md): định nghĩa 11 thẻ, mỗi thẻ có ví dụ thật.

## Các bước
1. Mở `data/manual/50_mau.csv` (tải về giống W2-03). Các dòng stt 1–25 (XNLI) là phần t đã làm, **m xem để làm theo cách viết**.
2. Với mỗi dòng stt 26–50, điền 3 cột:

   | Cột | Nội dung | Ví dụ |
   |---|---|---|
   | `the_hien_tuong` | 1–3 thẻ, cách nhau bằng dấu `;`. **Thẻ quyết định nhãn đặt đầu tiên** | `NUM;PARA` |
   | `giai_thich` | 1–2 câu giải thích **vì sao mẫu có nhãn này**, không chỉ ghi "có từ không" | "Premise nói ngày 3/4, hypothesis nói đầu tháng 4 → cùng thời điểm nên là entailment." |
   | `ghi_chu` | Nếu thấy nhãn gốc sai: `nghi_sai_nhan: <lý do>`. Nếu không thì để trống | |

3. ViANLI là dữ liệu **đối kháng** (adversarial): người viết hypothesis cố tình tạo câu để mô hình dự đoán sai.
   Với mỗi mẫu, nếu thấy chỗ khiến mô hình dễ sai thì ghi vào giải thích. Ví dụ: hypothesis trùng lặp nhiều từ với premise
   nhưng nhãn là neutral, hoặc phải suy luận về ngày tháng mới ra nhãn.
4. Lưu dạng CSV (giữ nguyên tên file và các cột), rồi đưa lên GitHub theo mục **Lưu và nộp** bên dưới.

## Tự kiểm tra
- Mỗi dòng có thẻ thuộc danh sách 11 thẻ. Thẻ `TRANS` (lỗi dịch) chỉ dùng cho XNLI, không dùng cho ViANLI.
- Mỗi dòng có giải thích. T sẽ chạy script kiểm tra, có lỗi t báo lại.

## Lưu và nộp
- **File** `data/manual/50_mau.csv`: trên GitHub vào thư mục `data/manual/` → **Add file → Upload files** → kéo file vào (giữ nguyên tên `50_mau.csv` để thay file cũ) → thông điệp commit **`W2-02: <việc đã làm>`** → **Commit changes**.

T kiểm tra bằng `python scripts/check_manual.py` (định dạng, thẻ, kappa).

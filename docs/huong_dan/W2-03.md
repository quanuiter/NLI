# W2-03 – Gán nhãn độc lập 25 mẫu ViANLI (Quang; phần XNLI t đã xong)

**Mục tiêu:** m tự gán nhãn 25 cặp câu khi **chưa biết nhãn gốc**, rồi so với nhãn gốc để đo mức đồng thuận giữa người và nhãn gốc
(Cohen's kappa). Kết quả đưa vào báo cáo mục 2. Phần XNLI của t: trùng 48%, kappa 0,22.

**File:** `data/manual/gan_nhan_doc_lap_A.csv`. Gồm 25 cặp câu ViANLI, đã ẩn nhãn gốc và `id`.

## Lưu ý
- **Làm task này TRƯỚC W2-02.** Trước khi gán xong, **không mở `50_mau.csv`**, vì file đó có nhãn gốc.
- Không tra Google. Mẫu nào phân vân vẫn chọn một nhãn, không để trống.

## Các bước
1. Tải file: trên GitHub mở file → bấm **Download raw file** (biểu tượng mũi tên tải xuống).
   Mở bằng Excel hoặc Google Trang tính (*Tệp → Nhập → Tải lên*).
2. Mỗi dòng có premise (tiền đề) và hypothesis (giả thuyết). Coi premise là đúng, rồi xét hypothesis:

   | Hypothesis… | Ghi vào cột `nhan_tu_gan` |
   |---|---|
   | chắc chắn đúng | `entailment` |
   | chắc chắn sai (hai câu không thể cùng đúng) | `contradiction` |
   | không xác định được đúng hay sai | `neutral` |

   Ghi đúng chính tả 3 nhãn trên, viết thường.
3. Lưu lại dạng **CSV**, giữ nguyên tên file và các cột, rồi đưa lên GitHub theo mục **Lưu và nộp** bên dưới.

## Tự kiểm tra
- Đủ 25 dòng có nhãn hợp lệ. T sẽ chạy script kiểm tra và báo kappa.

## Lưu và nộp
- **File** `data/manual/gan_nhan_doc_lap_A.csv`: trên GitHub vào thư mục `data/manual/` → **Add file → Upload files** → kéo file vào (giữ nguyên tên `gan_nhan_doc_lap_A.csv` để thay file cũ) → thông điệp commit **`W2-03: <việc đã làm>`** → **Commit changes**.

T kiểm tra bằng `python scripts/check_manual.py` (định dạng, thẻ, kappa).

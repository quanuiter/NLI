# W2-03 – Gán nhãn độc lập (phần của A – Quang; phần của Quân đã xong)

**Mục tiêu:** tự gán nhãn 25 cặp câu ViANLI khi **chưa biết đáp án**, để đo xem con người đồng ý với nhãn gốc đến đâu (Cohen's kappa).

**File:** `data/manual/gan_nhan_doc_lap_A.csv` (25 câu ViANLI, đã ẩn nhãn và id).

## Quy tắc quan trọng
- **Làm task này TRƯỚC W2-02.** **Không mở `50_mau.csv`** cho đến khi gán xong, vì file đó có đáp án.
- Không tra Google. Câu nào phân vân vẫn chọn một nhãn, không để trống.

## Các bước
1. Tải file về: trên GitHub mở file → nút **Download raw file**. Mở bằng Excel hoặc Google Trang tính
   (*Tệp → Nhập → Tải lên*, dấu phân cách: dấu phẩy).
2. Với mỗi dòng, coi premise là sự thật rồi hỏi: *"Nếu premise đúng thì hypothesis thế nào?"*

   | Hypothesis… | Ghi vào `nhan_tu_gan` |
   |---|---|
   | chắc chắn đúng | `entailment` |
   | chắc chắn sai (hai câu không thể cùng đúng) | `contradiction` |
   | có thể đúng, có thể sai | `neutral` |

   Viết thường, đúng chính tả. Đọc thêm mục 1 trong [huong_dan_gan_the.md](../../data/manual/huong_dan_gan_the.md).
3. Lưu lại dạng **CSV**, giữ nguyên tên file và các cột. Đưa lên repo (thay file cũ) hoặc gửi Quân.

## Tự kiểm tra
- Chạy `python scripts/check_manual.py` → dòng `Gán nhãn độc lập A: 25/25 mẫu hợp lệ`.

## Khi xong
Đổi W2-03 sang **Hoàn thành**. Sau đó mới làm W2-02.

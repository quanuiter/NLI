# W3-02 – Thiết lập fine-tune PhoBERT (B – Quân)

**Mục tiêu:** notebook fine-tune `vinai/phobert-base` cho bài toán cặp câu chạy được trên Colab, đã thử nhanh trên 1.000 mẫu.
Phần này dùng lại cho mọi lần chạy PhoBERT (W3-03, W4-01–03) và XLM-R (W4-04).

**File sẽ có:** `src/transformer.py` (dùng chung cho PhoBERT và XLM-R), `scripts/run_transformer.py`, `notebooks/05_phobert.ipynb`.

## Kiến thức cần nắm
- **Fine-tune:** lấy mô hình đã học tiếng Việt (PhoBERT), thêm một lớp phân loại 3 nhãn lên trên, rồi huấn luyện tiếp toàn bộ trên dữ liệu NLI.
- **Đầu vào cặp câu:** tokenizer tự ghép `<s> premise </s></s> hypothesis </s>`. PhoBERT đọc cả hai câu cùng lúc
  (self-attention giữa mọi từ của hai câu). Đây là khác biệt lớn nhất so với M2, M3 vốn mã hóa từng câu riêng.
- **Bắt buộc dùng bản đã tách từ:** `load_scenario(s, segmented=True)`. Giải thích chi tiết trong `data/manual/ghi_chu_tach_tu.md`.

## Các bước
1. Colab: chọn GPU T4. Chạy ô 0 (Drive, clone, cài thư viện).
2. Tải tokenizer và mô hình:
   ```python
   from transformers import AutoTokenizer, AutoModelForSequenceClassification
   tok = AutoTokenizer.from_pretrained("vinai/phobert-base")
   model = AutoModelForSequenceClassification.from_pretrained("vinai/phobert-base", num_labels=3)
   ```
3. **Chọn `max_len`:** token hóa cặp câu của train, xem phân bố độ dài token. PhoBERT tối đa 256 vị trí.
   Chọn mức phủ khoảng 99% cặp câu (ViANLI có lẽ khoảng 80–128).
4. **Cấu hình Trainer** (Hugging Face): đánh giá trên dev mỗi epoch, độ đo macro-F1, giữ checkpoint tốt nhất
   (`load_best_model_at_end=True`, `metric_for_best_model="macro_f1"`), `fp16=True`, `seed`.
   Hai cấu hình cần thử (ghi chú ở kế hoạch):
   - A: lr 2e-5, batch 32, 3 epoch;
   - B (theo bài ViANLI): lr 1e-5, batch 16, 7 epoch, max_len 256.
5. **Chạy thử 1.000 mẫu train, 200 mẫu dev, 1 epoch** để bắt lỗi (vài phút). Kiểm tra pipeline end-to-end:
   dự đoán ra đúng 3 nhãn và `evaluate_and_save(model='M4', ...)` lưu được file.
6. Viết hàm dùng chung `run(model_name, scenario, seed, cfg)`. Đổi `model_name="xlm-roberta-base"` và `segmented=False`
   là chạy được M5.

## Tự kiểm tra
- Lần chạy thử không lỗi, loss giảm, file kết quả đúng định dạng (giống M2).
- Thời gian 1 epoch ViANLI (8.012 cặp) trên T4: ghi lại để ước lượng thời gian XNLI 100k (W4-01).
- GPU hết bộ nhớ (CUDA out of memory): giảm batch hoặc max_len, hoặc bật `gradient_accumulation_steps`.

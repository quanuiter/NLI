# W3-06 – Script tổng hợp bảng kết quả (Quang)

**Mục tiêu:** viết `scripts/make_table.py`. Script đọc mọi file `results/*.json` và xuất 2 file:
- `results/summary.csv`: mỗi dòng là một tổ hợp mô hình × kịch bản × tập kiểm tra, gồm trung bình, độ lệch chuẩn và số seed của accuracy và macro-F1;
- `results/summary_bang.csv`: bảng định dạng sẵn để đưa vào báo cáo mục 4. Mỗi dòng là một mô hình, mỗi cột là một cặp kịch bản · tập kiểm tra,
  mỗi ô là macro-F1 (%) dạng `44,3 ± 0,5`.

Mỗi lần có kết quả mới thì chạy lại script này, bảng trong báo cáo luôn khớp với `results/`.

## Kiến thức cần nắm
- Mỗi lần chạy `evaluate_and_save(...)` tạo một file `results/<mô hình>_<kịch bản>_<tập kiểm tra>_seed<seed>.json`.
- Hàm `summarize()` trong `src/evaluate.py` (t viết sẵn) đã gộp các file đó và tính trung bình, độ lệch chuẩn theo seed.
  Script của m chỉ cần gọi hàm này, lưu kết quả, rồi **xoay bảng** (pivot) thành dạng mô hình × cột.

## Các bước
1. Trên GitHub, vào thư mục `scripts/` → **Add file → Create new file** → đặt tên `make_table.py`.
2. Dán đoạn code dưới đây. Đọc từng dòng chú thích để hiểu, khi review chéo (W3-07) t sẽ hỏi.
   ```python
   """Tổng hợp mọi file results/*.json thành bảng kết quả cho báo cáo.

   Chạy:  python scripts/make_table.py
   Ra:    results/summary.csv       (mô hình × kịch bản × tập kiểm tra: trung bình, độ lệch chuẩn qua các seed)
          results/summary_bang.csv  (bảng định dạng sẵn để đưa vào báo cáo)
   """
   import sys
   from pathlib import Path

   sys.path.insert(0, str(Path(__file__).resolve().parents[1]))   # để import được src/ khi chạy từ thư mục gốc repo

   from src.evaluate import RESULTS_DIR, summarize

   THU_TU_MO_HINH = ["M0", "M1", "M1h", "M2", "M3", "M4", "M5"]
   THU_TU_COT = [("S1", "xnli_test"), ("S1", "vianli_test"), ("S1", "vinli_test"),
                 ("S2", "vianli_test"), ("S2", "vinli_test"),
                 ("S3", "vianli_test"), ("S3", "vinli_test")]


   def dinh_dang(mean, std, n):
       """0.4431, 0.0052, 3 -> '44,3 ± 0,5'; chỉ có 1 seed -> '44,3'."""
       s = f"{mean * 100:.1f}"
       if n > 1:
           s += f" ± {std * 100:.1f}"
       return s.replace(".", ",")


   def main():
       bang = summarize()
       if bang.empty:
           print("Chưa có file kết quả nào trong", RESULTS_DIR)
           return
       bang.to_csv(RESULTS_DIR / "summary.csv", index=False)

       # Mỗi ô: macro-F1 đã định dạng; xoay thành dòng = mô hình, cột = (kịch bản, tập kiểm tra)
       bang["o"] = [dinh_dang(r.macro_f1_mean, r.macro_f1_std, r.macro_f1_count) for r in bang.itertuples()]
       rong = bang.pivot_table(index="model", columns=["scenario", "test_set"], values="o", aggfunc="first")
       cot = [c for c in THU_TU_COT if c in rong.columns]
       dong = [m for m in THU_TU_MO_HINH if m in rong.index]
       rong = rong.reindex(index=dong, columns=cot).fillna("–")
       rong.columns = [f"{s} · {t.replace('_test', '')}" for s, t in rong.columns]
       rong.to_csv(RESULTS_DIR / "summary_bang.csv", encoding="utf-8-sig")   # utf-8-sig: Excel đọc đúng tiếng Việt
       print("Macro-F1 (%) trên tập kiểm tra, trung bình ± độ lệch chuẩn qua các seed:")
       print(rong.to_string())


   if __name__ == "__main__":
       main()
   ```

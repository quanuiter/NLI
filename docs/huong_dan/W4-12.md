# W4-12 – Chạy M7: LLM Qwen2.5-7B-Instruct phân loại bằng prompt (Quang)

**Mục đích.** So sánh một mô hình ngôn ngữ lớn tổng quát (không huấn luyện trên dữ liệu NLI của nhóm) với các mô hình
được fine-tune (PhoBERT, M6). Mô hình đọc prompt trắc nghiệm A (suy ra được) / B (không xác định) / C (mâu thuẫn) và chọn chữ có
xác suất cao nhất. Code do Quân viết (`src/llm.py`, `scripts/run_llm.py`); Quang chỉ cần chạy.

**Thời gian:** khoảng 60–90 phút GPU T4 (lần đầu tải mô hình khoảng 15 GB).

## Các bước
1. Colab → File → Open notebook → tab GitHub → `quanuiter/NLI` → `notebooks/08_llm.ipynb`.
2. Runtime → Change runtime type → **T4 GPU** → Save.
3. Chạy từng ô từ trên xuống; đọc dòng **"Đạt khi"** dưới các ô kiểm tra.
   - Ô kiểm tra đầu in **phiên bản thư viện**: chụp gửi Quân (cho báo cáo mục 4.1).
   - Hết bộ nhớ GPU: thêm `--batch-size 2` vào cuối các lệnh `run_llm.py`.
4. Colab bị ngắt: chạy lại ô đầu, rồi ô đang dở. Phần nào đã có kết quả sẽ được bỏ qua.
5. Ô cuối phải in `Đủ 9 file kết quả. Xong W4-12.`

## Lưu và nộp
- Kết quả tự nằm ở Drive chung `NLI/results/` (`M7_S0_*`, `M7_FS_*`). Không cần commit, Quân đồng bộ.
- Sheet, dòng W4-12: **Đang review**, nhắn Quân.

## Quân kiểm tra
- Đủ 9 file; `config.pretrained` = `Qwen/Qwen2.5-7B-Instruct`, `load_in_4bit` = true, `prompt_version` = v1.
- FS: 3 seed có `demo_ids` khác nhau, mỗi bộ 6 ví dụ (2 mỗi nhãn), đều thuộc ViANLI train (không lấy từ test).
- Xem `pred_distribution`: nếu dồn hết vào một nhãn thì mô hình bị lệch nhãn, ghi vào phân tích.

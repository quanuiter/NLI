# W4-10 – Chạy M6: mDeBERTa đã học NLI (Quang)

**Mục đích.** M4, M5 bắt đầu từ PhoBERT, XLM-R chưa biết gì về NLI. M6 bắt đầu từ mDeBERTa-v3-base đã học NLI trên
khoảng 2,7 triệu cặp câu ở 27 ngôn ngữ (có tiếng Việt, gồm cả dữ liệu đối kháng ANLI dịch máy), rồi fine-tune nhẹ thêm trên ViANLI.
Đây là cách nhóm thử nâng điểm phân loại. Code do Quân viết (`src/transformer.py`, `scripts/ensemble.py`); Quang chỉ cần chạy.

**Thời gian:** khoảng 60–75 phút GPU T4. Có thể để máy tự chạy, chỉ cần quay lại xem từng ô đã xong chưa.

## Các bước
1. Mở Colab → File → Open notebook → tab GitHub → nhập `quanuiter/NLI` → chọn `notebooks/07_m6.ipynb`.
2. Runtime → Change runtime type → **T4 GPU** → Save.
3. Chạy từng ô từ trên xuống. Dưới mỗi ô quan trọng có dòng **"Đạt khi"**: đọc rồi mới chạy ô tiếp theo.
   - Ô đầu hỏi quyền truy cập Drive: bấm cho phép (dùng tài khoản có Drive chung `NLI`).
   - Ô chạy thử in `LOSS BỊ NAN` thì làm theo hướng dẫn ngay dưới ô đó (thêm `--no-fp16`).
4. Colab bị ngắt giữa chừng: chạy lại ô đầu, rồi chạy lại ô đang dở. Lần chạy nào đã có đủ file kết quả sẽ được bỏ qua.
5. Ô cuối phải in `Đủ 11 file kết quả. Xong W4-10.`

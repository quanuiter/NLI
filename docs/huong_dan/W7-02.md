# W7-02 – Thêm seed cho M2, M3, XLM-R (Quân chạy)

**Mục đích.** Báo cáo mục 5.6 ghi hạn chế "XLM-R và các mô hình ở S1 chỉ chạy 1 seed". Task này chạy thêm seed 123 và 2024
để mọi mô hình nơron chính đều có trung bình ± độ lệch chuẩn qua 3 seed. Không có code mới, chỉ chạy lại lệnh cũ với seed khác.
Người chạy là Quân vì XLM-R S3 cần checkpoint `checkpoints/M5_S1_seed42` trên Drive của Quân.

**Thời gian:** khoảng 2,5 giờ GPU T4.

## Các bước
1. Colab → GitHub `quanuiter/NLI` → `notebooks/10_them_seed.ipynb`, bật **T4 GPU**. Đăng nhập Drive bằng tài khoản có thư mục `NLI` chung.
2. Chạy từ trên xuống (ô đầu tự tạo `emb_fasttext.npz` nếu chưa có). Ô XLM-R S3 in `Có checkpoint XLM-R S1 seed 42: True` mới chạy được.
3. Lệnh M2, M3 không tự bỏ qua lần đã chạy: nếu đã chạy xong bước 1 thì lần sau bỏ qua ô đó.
4. Ô cuối phải in `Đủ 26 file kết quả. Xong W7-02.`

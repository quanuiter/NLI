# W7-01 – Khử mẹo trùng từ cho PhoBERT (Quang chạy)

**Mục đích.** Kiểm tra trực tiếp phát hiện chính của đồ án: PhoBERT học trên XNLI dưới mức ngẫu nhiên trên ViANLI vì học mẹo
"trùng nhiều từ → suy ra được". Nếu bắt PhoBERT bỏ mẹo đó khi huấn luyện mà điểm ViANLI tăng thì nhận định được chứng minh;
nếu không tăng thì mẹo trùng từ không phải nguyên nhân duy nhất. Kết quả nào cũng viết vào báo cáo được.
Code do Quân viết (`src/debias.py`, `src/transformer.py`, mô hình `M4P`); Quang chỉ cần chạy.

**Thời gian:** khoảng 2 giờ GPU T4, chia làm nhiều lần được.

## Các bước
1. Colab → File → Open notebook → GitHub `quanuiter/NLI` → `notebooks/09_khu_meo.ipynb`, bật **T4 GPU**.
2. Chạy từ trên xuống. Ô kiểm tra đầu báo thiếu file tách từ thì chạy ô `segment_data.py` ngay dưới (15–20 phút).
3. Colab bị ngắt: chạy lại ô đầu rồi ô đang dở; lần chạy nào đã có kết quả sẽ được bỏ qua.
4. Ô cuối phải in `Đủ 15 file kết quả. Xong W7-01.`

## Lưu và nộp
Kết quả tự nằm ở Drive `NLI/results/` (`M4P_S1_*`, `M4_S1_*_seed123/2024`). Sheet W7-01 → **Đang review**, nhắn Quân.

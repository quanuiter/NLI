# W3-07 – Review code chéo (A + B)

**Mục tiêu:** mỗi người đọc code của người kia để bắt lỗi trước khi chốt số liệu, và để **cả hai hiểu toàn bộ code**
(khi bảo vệ, thầy hỏi ai cũng phải trả lời được).

## Phân công
- **Quang đọc của Quân:** `src/data.py`, `src/evaluate.py`, `src/m2.py`, `src/m3.py`.
- **Quân đọc của Quang:** `notebooks/01_eda.ipynb`, `notebooks/02_m1.ipynb`.

## Các bước
1. Trên GitHub: tab **Commits** → bấm commit cần xem → bấm số dòng để để lại bình luận. Hoặc mở file → **Blame** để xem ai viết dòng nào.
2. Đi theo danh sách kiểm tra dưới đây, ghi bình luận cho từng điểm chưa ổn.
3. Người viết code sửa, rồi trả lời bình luận.

## Danh sách kiểm tra
- [ ] Dữ liệu chỉ lấy qua `load_scenario` / `load_split` (không tự đọc file khác, không tự chuẩn hóa lại).
- [ ] **Không dùng test để chọn siêu tham số.** Mọi vòng thử cấu hình chỉ dùng `d['dev']`.
- [ ] **Không dùng cột `id`** làm đặc trưng (id ViANLI chứa mã nhãn).
- [ ] Có `set_seed(...)` trước khi huấn luyện. Chạy lại ra cùng số.
- [ ] Kết quả lưu bằng `evaluate_and_save`, `config` ghi đủ siêu tham số.
- [ ] Không có số "điền tay" trong báo cáo mà không có file `results/` tương ứng.
- [ ] Người review **giải thích lại được** từng hàm chính bằng lời của mình (thử nói cho người kia nghe).

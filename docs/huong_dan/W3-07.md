# W3-07 – Đọc chéo code của nhau (cả hai)

**Làm để làm gì:** bắt lỗi trước khi chốt điểm. Quan trọng hơn: **đứa nào cũng hiểu hết code**,
vì lúc bảo vệ thầy hỏi ai thì người đó phải trả lời được.

## Ai đọc gì
- **M (Quang) đọc của t:** `src/data.py`, `src/evaluate.py`, `src/m2.py`, `src/m3.py`.
- **T đọc của m:** `notebooks/01_eda.ipynb`, `notebooks/02_m1.ipynb`.

## Các bước
1. Trên GitHub: tab **Commits** → bấm vào lần lưu muốn xem → di chuột vào dòng code → bấm dấu **+** để ghi bình luận.
2. Đọc theo danh sách bên dưới, chỗ nào chưa ổn hoặc không hiểu thì ghi bình luận hỏi.
3. Người viết code sửa hoặc giải thích lại.

## Danh sách kiểm tra
- [ ] Dữ liệu chỉ lấy qua `load_scenario` / `load_split`, không tự đọc file riêng.
- [ ] **Không dùng tập thi (test) để chọn núm vặn.** Chọn chỉ dựa trên `d['dev']`.
- [ ] **Không dùng cột `id`** (id của ViANLI chứa luôn đáp án).
- [ ] Có `set_seed(...)` trước khi huấn luyện, chạy lại ra đúng số cũ.
- [ ] Kết quả lưu bằng `evaluate_and_save`, `config` ghi đủ núm vặn đã dùng.
- [ ] Con số nào trong báo cáo cũng có file trong `results/` đi kèm.
- [ ] Người đọc **nói lại được** từng hàm chính làm gì bằng lời của mình (nói thử cho người kia nghe).
